scythebill-android is a small application which supports browsing and querying a Scythebill .bsxm file.

It does not support editing on mobile: data entry should either on the desktop, or with one of the excellent
mobile data entry apps (like eBird, iNaturalist, BirdTrack, BirdLasser, etc.).

It only contains the Android-specific source code, and depends on the model/ and xml-parser/ packages in
https://bitbucket.org/scythebill/scythebill-birdlist/
